## Последняя проверка

23 октября выполнено [сравнение AgentAI с воспроизведением Big RAG](rag-systems-comparison-20261023.md):
14 одинаковых вопросов без подсказки файла, все 28 ответов оценены по источникам.
Средняя оценка AgentAI — 3,0/5, воспроизведения Big RAG — 2,07/5; оценку не ниже 4/5
получили 5/14 и 3/14 ответов соответственно. Нативный вызов плагина запрещён
API LM Studio (403); алгоритм поиска воспроизведён и сверен с Vectra.
Все 30 общих PDF совпали по SHA-256. Это сравнение конвейеров, а не изолированный
тест embedding-моделей. Выявлен дефект: первичный поиск AgentAI нашёл 13/13
эталонных файлов, но до генерации дошли только 7/13. Дополнительный отбор и
соседние пакеты вытесняют часть правильной первичной выдачи при упаковке.
В рамках этого прогона приложение не изменялось; дефект ещё не исправлен.

Текущая embedding-база — [Qwen на CPU](qwen-embedding-migration-20261022.md),
32 документа / 96 фрагментов. Результаты ниже относятся к предыдущим этапам.

22 октября до изменения профиля генерации выполнена отдельная
[оценка 24 живых ответов](answer-evaluation-20261022.md):
17 удовлетворительных по независимой сверке, семь требуют исправления.
Автоматические критерии дали 22/24 и пропустили часть смысловых ошибок.
Ниже сохранены результаты предыдущих backend- и инфраструктурных проверок;
они не означают правильность всех ответов модели.

Затем применён [рекомендуемый профиль Qwen](model-configuration.md), проверены
параметры запроса, инструменты и готовность API. В последующем
[испытании профиля](qwen-recommended-profile-evaluation-20261022.md) сохранены
24 попытки. Основной сопоставимый блок: 15/18 удовлетворительных ответов
против 16/18 прежде; медиана 14 самостоятельных вопросов — 76,42 с против
14,02 с. Дополнительные повторы остановлены после ошибки нехватки памяти
служебного окружения; последние четыре дополнительные попытки отделены
от основного сравнения. API восстановлен, `/ready` вернул 200.

- Backend: **229 passed** с отдельной временной PostgreSQL.
- Синтетический поиск: **38/38**, Recall@3 и MRR@6 равны 1 на этом наборе.
- Синтаксис: 125 файлов Python; архитектура: 73 модуля без циклов импортов
  и зависимостей внутренних модулей от HTTP.
- HTTP-диалог: четыре вопроса, **4/4** автоматических проверок с нужными
  источниками и разными ответами; тестовая история удалена.
- После последнего исправления числовых кодов: отдельная проверка **1/1**.
- При применении обновления 73 исполняемых файла совпали с локальными
  исходниками; готовность API подтверждена HTTP 200.

Это результаты конкретных прогонов, а не оценка точности всех ответов.
Полный промежуточный прогон нашёл 13 контрольных документов в итоговых
материалах, но также выявил ошибки содержания. После последних поправок
выполнялись адресные проверки и полный backend-набор; итоговый полный прогон
всех 14 естественных вопросов на том этапе заново не выполнялся; новый прогон
23 октября приведён выше.
Подробности и локальные артефакты — в [текущем отчёте](natural-retrieval-fix.md).
