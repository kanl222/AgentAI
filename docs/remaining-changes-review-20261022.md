# Проверка оставшихся изменений — 22 октября 2026

Проверены незакоммиченные файлы относительно `463e5a4`: декораторы доступа,
их применение в сценариях и HTTP, пилот AutoRAG и стенд CPU embeddings/reranking.
Отдельного исходного задания на рефакторинг доступа нет; проверялось сохранение
существующих ролей, ограничений источников и совместимости прямых вызовов.

## Standards

Независимая проверка обнаружила два функциональных дефекта:

- Сокращённый `@core_require` ошибочно превращал защищённую функцию в фабрику
  декораторов. Исправлено распознавание формы вызова; добавлены sync/async тесты.
- Явный `p=None` или `user=None` мог заменяться словарём из тела запроса с полем
  `roles`. Явно объявленный пользователь теперь имеет приоритет, включая его отсутствие.

Дополнительно отмечено возможное дублирование: sync/async обёртки повторяли
привязку аргументов и проверку доступа. Эта логика вынесена в общий помощник.
Это замечание к сопровождению, а не нарушение документированного стандарта.
Нарушений направления зависимостей между сценариями и HTTP не найдено.

## Spec

Проверка сохранения поведения и требований CPU-эксперимента обнаружила три замечания:

- Неразрешённый `source='body.source'` возвращал `None`, отключая ограничение
  источника. Теперь заданный, но неразрешённый источник запрещает выполнение.
  Также исправлена обработка литералов с точкой, например `repo.private`:
  такой источник сохраняет проверку прав.
- Сокращённый совместимый декоратор был сломан; исправление описано выше.
- README CPU-стенда называл Nomic текущей рабочей моделью и не фиксировал
  прерванное сравнение. Теперь описаны переход на Qwen и фактическое покрытие:
  reranking Nomic 14 вопросов, Qwen — ни одного; полного вывода нет.

Все перечисленные замечания исправлены. Новых требований к рабочему поиску
или смены настроек моделей этот коммит не вводит.
