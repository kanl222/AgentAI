Подключение

Ключ хранится только в памяти этой страницы. Для загрузки и управления нужен личный ключ с ролями reader и indexer. Общий ключ WebUI даёт общую область доступа.

Введите ключ для доступа к данным.

Диалог сохраняется в PostgreSQL. При смене ключа выберите свой диалог заново.
