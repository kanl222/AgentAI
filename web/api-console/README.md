# Консоль API

Отдельный технический сайт: `index.html`, `app.js`, `app.css`. Отдаётся сервером AgentAI на http://localhost:8000/ и по прежнему адресу `/library`.

Проверка произвольного запроса к этому API показывает HTTP-статус, время и JSON-ответ. Также доступны тестовый диалог, загрузка документов, синхронизация GitLab и просмотр заданий. Права определяются личным ключом API. Для обычного общения используйте отдельный `web/chat`.

Структура сохранена без сторонних библиотек. Пути `/assets/library.js` и `/assets/library.css` оставлены для совместимости и ведут к файлам этой консоли.
