# Сравнение поиска на CPU

Изолированный эксперимент для Nomic Embed Text v1.5 и Qwen3-Embedding-0.6B,
каждая — без reranking и с Qwen3-Reranker-0.6B. Все три модели в Q8_0;
используется CPU-сборка llama.cpp b11669 с `-ngl 0 --device none`.
Приложение, его настройки, PostgreSQL и Qdrant не изменяются.

Статус опыта 22 октября: обе ветки embeddings завершены на 18 вопросах.
Reranking прерван после 14 вопросов Nomic; ветка Qwen с reranking не выполнялась.
Полного сравнения четырёх вариантов пока нет; `summarize` требует завершения всех
веток. Текущая рабочая система уже переведена на Qwen embeddings без reranking;
см. [отчёт миграции](../../docs/qwen-embedding-migration-20261022.md).

Нужен локальный снимок `work/evaluation-20261022-corpus.json` и сохранённые
вопросы `work/evaluation-20261022-{natural,extra}.json`. Они содержат частные
документы и в репозиторий не включаются. Разметка нужных фрагментов и разделение
на development/holdout взяты из `scripts/autorag_pilot.py` и проверяются хешами.

Из корня проекта на Windows:

```powershell
python -m venv work/cpu-retrieval-comparison/.venv
work/cpu-retrieval-comparison/.venv/Scripts/python.exe -m pip install -r examples/cpu-retrieval-comparison/requirements.txt
work/cpu-retrieval-comparison/.venv/Scripts/python.exe scripts/prepare_cpu_retrieval.py
work/cpu-retrieval-comparison/.venv/Scripts/python.exe scripts/compare_cpu_retrieval.py nomic
work/cpu-retrieval-comparison/.venv/Scripts/python.exe scripts/compare_cpu_retrieval.py qwen
work/cpu-retrieval-comparison/.venv/Scripts/python.exe scripts/compare_cpu_retrieval.py rerank
work/cpu-retrieval-comparison/.venv/Scripts/python.exe scripts/compare_cpu_retrieval.py summarize
```

Каждый этап запускает один процесс сервера на `127.0.0.1:18971`, шесть CPU-потоков,
один слот, затем завершает только свой процесс. Нужен свободный порт.
При устойчивом снижении доступной памяти ниже 256 МиБ сервер теста останавливается.
У Windows принудительное штатное завершение тестовым процессом может давать код 1;
проверяйте наличие полных результатов и поле `shutdown`, а не только этот код.

Файлы сохраняются в `work/cpu-retrieval-comparison/`: версии и хеши исходных
данных, сведения о моделях, векторы, ранжирования, задержки, ресурсы и `results.json`.
Готовая часть reranking может быть продолжена после прерывания, если кандидаты совпадают.
Для чистого повторного измерения используйте отдельную сохранённую копию каталога
результатов: команды этапов embeddings заменяют свои файлы результатов.

У Nomic используются `search_query:`/`search_document:`, у Qwen — рекомендованная
инструкция на стороне запроса. Оба варианта используют одинаковый BM25 из проекта,
слияние RRF и одинаковый приоритет совпавших заголовков. До reranking выбираются
20 кандидатов, итог — 6. Полные фрагменты передаются без обрезки.

Nomic GGUF объявляет исходное окно 2048. Для длинных фрагментов используется
[описанный авторами YaRN .75](https://huggingface.co/nomic-ai/nomic-embed-text-v1.5-GGUF),
исходное окно явно задано как 2048; дополнительно обновлён объявленный лимит
метаданных, иначе текущий llama-server ограничивает слот старым значением.
Фактический предел слота и длины запросов видны в журнале. Это исследовательская
конфигурация, отличная от прежнего рабочего Nomic Q4_K_M с окном 2048.
Рабочий Qwen и данный сравнительный стенд имеют отдельные настройки.

`complete` — найдены все размеченные группы свидетельств; `recall` — средняя доля
найденных групп; `mrr` — обратная позиция первого нужного фрагмента; `ndcg` —
оценка порядка нужных фрагментов. Для каждой метрики сохраняются отдельные вопросы.
Метрики измеряют поиск, не корректность сгенерированного ответа. В наборе 18
вопросов с известными ответами; отказы на вопросы без ответа здесь не оцениваются.
Разметка содержит проверенные нужные страницы, но может не перечислять все альтернативные.
Задержки запроса не включают загрузку модели и построение индекса; время индекса
и загрузки приводится отдельно. При двух постоянно загруженных моделях суммарную
память и задержку под нагрузкой нужно измерять отдельным эксплуатационным тестом.
