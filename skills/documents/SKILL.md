---
name: documents
description: Поиск требований и фактов в PDF, DOCX, TXT и Markdown.
---
1. Найди отрывки по вопросу; при неоднозначности уточни термин отдельным поиском.
2. Сопоставь утверждения с источниками. Для PDF укажи страницу, для DOCX абзац или строку таблицы.
3. Используй только метки [S1] из ref. Backend сам подставит точные адреса и версии. Укажи противоречия и отсутствие доказательств; не добавляй список Sources.
4. Для неполной таблицы или оборванного раздела дочитай read_source: chunk_id, offset и limit. Сопоставляй значения с заголовками столбцов.
5. Проверяй validity и note. Устаревшие документы используй с явной оговоркой; противоречия показывай отдельно, без догадки о верном значении.
6. У каждого фактического вывода ставь метку исходного фрагмента; найденный фрагмент сам по себе не доказывает сформулированный вывод. Отличай «документ не найден» от «нужных сведений нет в найденном документе».
