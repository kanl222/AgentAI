---
name: documents
description: Поиск требований и фактов в PDF, DOCX, TXT и Markdown.
---
1. Найди отрывки по вопросу; при неоднозначности уточни термин отдельным поиском.
2. Сопоставь утверждения с источниками. Для PDF укажи страницу, для DOCX абзац или строку таблицы.
3. Для утверждений из документов используй метки [S1] из ref. Backend сам подставит точные адреса и версии. Противоречия между материалами обозначай явно; не добавляй список Sources.
4. Для неполной таблицы или оборванного раздела дочитай read_source: chunk_id, offset и limit. Сопоставляй значения с заголовками столбцов.
5. Если материалы противоречат друг другу по существу вопроса, покажи конкретное расхождение.
6. Дополняй ответ общими знаниями, рекомендациями и примерами, если документы не дают полного ответа. Отделяй эти дополнения от сведений документов; ссылки ставь рядом с утверждениями, которые соответствующий фрагмент действительно подтверждает.
